# Generierung der drei Designrichtungen

Werkzeug: eingebautes image_gen, Modus ui-mockup. Referenz: logo.jpg (ergänzendes Schullogo). Alle Nachrichten, Namen, Fotos und Herz-Zahlen sind fiktive Designbeispiele. Die Bilder sind Designstudien, keine Browser-Screenshots.

Jede PNG-Tafel zeigt Desktop und Mobil. Nach Nutzerauswahl werden separate Detailansichten erstellt. Keine Richtung ist freigegeben.
